# Eldervale

An original browser-based low-poly medieval fantasy RPG in active development.

## Current prototype
Version 0.5: articulated adventurer with walking animation, point-and-click movement, gathering, inventory, merchant, and local saves.

## Hosting
Vercel static site. The project will eventually expand to server-authoritative multiplayer.

## Development
Game files are being migrated from the local prototype to this repository.
