# Authored wildlife assets

Hawk mesh, feather texture and baked wing animation: **Wildfire Games / 0 A.D.**, CC BY-SA 3.0. Source: https://github.com/0ad/0ad (archived upstream mirror). Original source files: `wildlife-source/hawk.dae` and `wildlife-source/hawk_flight.dae`. Texture: `wildlife-hawk.png`, upstream `binaries/data/mods/public/art/textures/skins/skeletal/animal_hawk.png`. Changes: axis conversion, wingspan normalization and baked morph frames. License: https://creativecommons.org/licenses/by-sa/3.0/ . Derivative mesh data in `wildlife-asset.js` retains this license.

Butterfly mesh, rig and wing animation: **Čestmír Dammer (CDmir)**, with TinyWorlds; diffuse UV texture based on photo documentation by **Rick Hoppmann**. **CC0 1.0**. Source: https://opengameart.org/content/butterfly-animated . Original editable file and supplied license: `wildlife-source/butterfly.blend` and `wildlife-source/license.txt`. Changes: axis conversion, scale normalization and baked animation. Texture: `wildlife-butterfly.png`.

These are downloaded artist-authored models, not generated geometry. The live game renders a small nearby population with paths and wing phases derived from the shared world seed and server clock. They are decorative wildlife, not independent combat NPCs.
