Start here

Open World studio or press F8 while signed in as owner. Use the Owner guide link in its header to return here. Changes save to the shared server immediately; the status line reports success or an error. Escape cancels placement. Use Server → Start maintenance while rebuilding, then End maintenance when ready. The game terminal accepts game commands only, not shell commands, JavaScript or SQL.

Build your world

World → New entity → Template selects an NPC, monster, building, scenery, terrain, station or item. Set Name, World X, World Z, Heading ° and Scale. Use my position fills coordinates; Spawn at coordinates saves there. Place with world click closes Studio so you can click the terrain. Escape cancels before placement.

To edit: filter the saved list or Select in world, choose the entity, change its fields and Save changes. Move with world click relocates it. Clone prepares a copy offset by 3 metres; save/place it to create the copy. Delete removes the saved entity; Restore returns it. Teleport here takes you to its coordinates. Actors includes original residents as well as your placed actors.

Terrain patches have a 2–30 metre radius and −8 to +8 metre elevation. Start with gentle changes away from foundations, paths and water; inspect the edges before adding more. Roads expose length 2–50 metres and width 1–8 metres. Castle walls/gates expose length 6–50 metres. Entity scale ranges from 0.25 to 5. Heading is in degrees; world locations use X and Z, not altitude.

Export world downloads active placed entities as JSON. Import world JSON ADDS entities, so importing an existing layout duplicates it. Each import accepts up to 200 entities and 2 MB. Keep exports as building-layout backups. An export larger than 200 entities needs splitting before import; exports do not include player accounts or full database backups.

Example: build a settlement

Choose a level open area. Place roads first, then buildings and walls, checking doors and entrances on foot. Add a bank building and a banker NPC, a market or merchant NPC, a furnace and a separate anvil, a cooking hearth, well/fountain and resource stations. Add lamps and scenery last, leaving walkable routes. Set service NPC roam to 0. Place armed guard templates at entrances and inspect their level, health and damage.

A building and its service are separate: a bank building alone does not automatically create a banker. A forge building is not a substitute for the furnace/anvil stations. Use the stations command to list your placed skilling stations. Tutorial start is set separately in Server; walk to your intended start and choose Set my position as new-character / tutorial start. Only new characters use it.

Eldervale Castle is centered around X −340, Z −305. The castle command teleports to its southern approach (−340, −237). Its buildings, residents and scenery can be edited through World and Actors.

NPCs, monsters and services

World → New entity offers templates with existing visuals and attack types. Set level, health, attack damage, seconds per turn, roam radius, respawn seconds and attack style. Respawn 0 means never. Can be attacked and Aggressive to nearby players are separate settings; a non-attackable NPC cannot be aggressive. Dialogue uses one page per line.

For shops, use an NPC with Service → Merchant / shop, or a market object. Add shop item creates a row with an item selector, Buy price, Sell price and Stock. Buy is what the player pays; Sell is what the player receives. Stock −1 is unlimited; finite stock is shared. Remove deletes a stock row. Empty custom stock uses the standard market. Save the entity after editing stock.

Set Service → Bank for a banker opening the shared bank. Dialogue only creates a resident. Other service choices use existing game mechanics; selecting a label does not create new scripted behavior.

Actors lists all residents and creatures, including original IDs beginning base:. Go to teleports to an actor. Freeze pauses it; Unfreeze resumes it. Respawn resets health and position. Delete removes it persistently until Restore. World controls buildings and scenery; terminal delete controls actors. Town guards attack hostile intruders, so keep guards present and stronger than local threats.

Items, icons and giving yourself supplies

Items is the complete searchable item library. Filter by name, ID or category and set Quantity. Add to inventory gives items directly to your backpack; Send to bank explicitly sends them to your unlimited bank. Equipment is granted one at a time. The 28-slot backpack still applies, so clear space if a grant is refused. Place in world lets you click a position for an owner-placed item entity. These persistent world entities are different from ordinary player drops, which expire after five minutes.

The custom item editor creates trade goods and healing consumables. Use a stable unique ID beginning custom_, then name, description, appearance, world model, prices, healing amount and stackability. Choose an appearance tile to synchronize the model. Save item publishes it to all players; choose an existing custom item to edit it. Renaming keeps its ID valid. Arbitrary uploaded meshes, new equipment types and scripted abilities require code; this editor does not create them.

Inventory, bank, shops and the library use rendered images of the canonical item meshes. Square and kite shields use separate silhouettes. Dropped items use those meshes flattened onto the ground. Bank notes wrap the same image in parchment. The item gallery below lists current built-in IDs and images; custom live items appear in the in-game Items library.

Skills, resources and recipes

World → New entity places rocks, trees and profession stations. Rocks expose Ore type. Trees expose Logs produced, Tree regrowth seconds and minimum/maximum logs. Choose the correct resource for your intended player level. Fishing uses shared shore spots; rods require bait, nets do not. Tools must be in inventory or wielded where applicable. A smithing hammer is a carried tool, not a weapon.

The Recipes tab lists current recipes. Select one to change its required skill/level, XP, action duration, station, ingredients, products, tools and enabled state. Ingredients are consumed; tools remain. Add/remove rows using the item selectors. New recipes need a unique recipe ID. Save recipe publishes to all players. Special existing recipes expose settings such as ore respawn, fire lifetime, crop growth/yield and success/burn chance.

Mining supplies ore; a furnace smelts ore into bars; an anvil and hammer turn bars into equipment. Matches or a reusable tinderbox light logs into a fire; matches are consumed. Cooking uses a hearth or campfire. Other stations support crafting, fletching, herblore, farming, runecrafting, construction, hunter, agility and thieving through their configured recipes. See the professions guide for ingredients and player workflows. Use recipes, recipe recipeID, skills and stations in Terminal for exact current requirements.

A recipe processes existing items through supported mechanics; it cannot invent a new animation or ability. Moving or entering combat interrupts timed actions. Check backpack space before processing.

Bank, drops and trade

Interact with a banker or a teller stand inside the bank to open banking. Bank doors only open/close; entering the building does not open banking automatically. Search and select a slot, choose a quantity, then Withdraw or Deposit. Double-click and right-click shortcuts are available. Bank storage has no slot limit. Physical nonstackable items occupy individual backpack slots.

Switch withdrawal to Note to withdraw eligible nonstackable items as stackable parchment notes. Notes cannot be wielded, eaten or used as tools/materials. Deposit them at a bank and withdraw as Item to use the physical items. Naturally stackable items such as bait keep their normal form.

Right-click an inventory item → Drop and choose a quantity. Other players immediately see and can collect it. Unclaimed ordinary drops expire after five minutes. Right-click the gold display to drop currency. Right-click another player → Trade to exchange items/gold: both parties review and confirm; edits reset acceptance. Owner-placed item entities are managed separately through World.

Server, players and moderation

Server controls welcome text, announcements shown for ten minutes, maintenance and a 15–3600 second restart countdown. Cancel countdown stops it. Restart saves characters and reloads connected clients; it does not reboot Hostinger or the database. Maintenance blocks entry for other players while you build.

Players lets the owner choose a saved character, grant items/gold, heal, teleport, bring them to you, and set skill levels (1–100). Select Staff role → Moderator and Set player role to promote someone; choose Player to revoke access. Use player UUIDs from this tab or players in Terminal. A last-save timestamp does not prove a player is online.

Moderators can kick, mute up to 24 hours, unmute, remove chat messages and resolve reports. World editing, item grants, bans and staff-role management remain owner-only. They cannot moderate another staff member. Access is checked on the server. Use a clear moderation reason and a duration in seconds. Reports and recent chat appear under Players.

Audit shows the latest 100 owner actions with before/after data and Export audit. It is a recovery reference, not an automatic whole-world undo. Export your layout before large edits.

Replace actorID, playerUUID, itemID and recipeID with IDs from the discovery commands. Quick building and NPC setup

Open World Studio → World → New entity. Use Quick setup to choose a furnished timber home, stone townhouse, inn, bank, smithy, great hall, chapel or armory. These presets use the current building library. Choose Stone walls, Furnished interior and a cottage's Interior layout before placing it.

Use the turn buttons or Face North/East/South/West to set direction. Small, Standard, Large and Grand are size shortcuts; the Scale field remains editable. Changes apply when you press Save changes or Place with world click. Confirm doors and walking routes after placement.

NPC presets include a resident, merchant, banker and guard. Set the NPC's name and dialogue (one page per line). For a shop, choose Merchant / shop and add stock using the item picker. Buy price is what the player pays; sell price is what the player receives. Stock −1 means unlimited. These are base prices. Limited stock automatically raises or lowers quotes with shared supply; unlimited stock keeps fixed prices. Sell quotes stay below buy quotes. Buy 10 shows its complete price across all ten units. If another trade changes the quote before purchase, the server rejects it so you can review the new total. Saving a merchant resets its stock to the editor quantities.

The Quests tab now publishes playable server-backed quests. Buildings support one to three stories with shared floor state, stairs and upper-floor placement. See the sections above for controls and limitations.

Create playable quests

  1. Place a resident NPC in World. Its name appears in the quest giver picker.
  2. Open Quests → New quest. Enter a name and dialogue/description, then choose the NPC where the quest starts and ends.
  3. Add one to eight objectives: collect original items and hand them in, talk to a specific NPC, or defeat a specific attackable NPC/monster. Choose the quantity. Kill counts are for that placed actor across its respawns, not every monster of that species.
  4. Choose gold, item and XP rewards. Preview the quest, enable Published, then Save quest. Drafts remain unavailable to players.
  5. Players open the scroll journal button or talk to the giver. They must stand near the giver to accept and hand in. Talk/defeat progress counts after acceptance; collected items are consumed when handed in. Leave inventory room for rewards.

Rewards are paid once. Accepted quests keep their original objectives and rewards when you edit or unpublish the definition. Unpublish prevents new acceptance while existing players can finish. Do not delete the giver or an objective actor while players still need them. Quest prerequisites and branching dialogue are not included in this version.

Stories, stairs and building interiors

World → Quick setup includes a three-story castle keep, two-story stone townhouse and two-story timber inn, plus the existing bank, smithy, chapel and armory presets. Use Stories (1–3), Upper-floor room and Third-story room to choose bedrooms, workshop, hall, chapel or armory. Stone walls, size, direction and furnished/empty remain editable.

Walk inside and approach the spiral stairs on the right rear side. Use Upstairs / Downstairs on screen, or E / Shift+E. Stair use changes the shared server floor by one level; it is an interaction rather than free climbing. The ceiling and higher stories hide while you are inside.

To put an object or NPC upstairs, go upstairs first, open World, choose its template, then Place with world click. Placement uses your current floor and building. Use my position also captures your floor. Other players see it on that floor. Dropped items remain on their floor. Upper-floor objects must stay inside their parent building. Remove upper-floor objects and move occupants downstairs before moving, resizing or deleting that building; grouped building relocation is not supported yet.

Eldervale Castle Keep has a ground-floor hall, first-floor profession workshop and second-floor chambers. The smithing anvil and furnace belong in the Royal Smithy; the mill is in the kitchen and runecrafting altar in the chapel. The workshop contains crafting and thieving stations.

Forest camp and expanded building supplies

The trail outside the castle now passes a permanent, seed-stable travelers’ campsite on the road toward Birchford. The castle, bridge, walls and interiors are unchanged. The exterior forest floor has gentler grades, extra ferns, visible grass, trees and rocks. Camp objects and NPCs are saved entities: select them in World to move, clone or delete them.

World → Quick setup includes ten new personas (outfitter, cook, herbalist, woodsman, scout, pilgrim, wagoner, wayfarer, storyteller and trail warden) and twelve camp props. Props include canvas tents, straw-and-wool bedding, log seats, a cooking tripod, wagon, sign, firewood, rope, lantern, table, stool and weapon rack. Edit NPC dialogue and merchant stock as usual. The cooking pot opens Cooking recipes; carry ingredients and stand within reach.

Items includes 26 additional foods and travel goods: fruit, soup, pie, pizza, fish, chicken, cloth, pelt, rope, candle, lantern, bedroll, letter, journal and bucket. Search the item name, then Add to inventory or Place in world. Item editor also offers the new rope, candle, lantern, bedroll, book, scroll and bucket mesh types.

The item-art audit covers 131 physical catalog entries and 116 note variants. Nonstackable items have parchment note icons using their original mesh image; naturally stackable goods retain their usual icon. All dropped items use their canonical mesh flattened against the ground, including notes. Existing item images and armor models were preserved.

Skill and profession increases now show a congratulations panel with an original five-second jingle. Press Continue to acknowledge it. If the increase also raised combat level, the combat congratulations follows. Notices wait until combat ends and other dialogs close, and do not replay simply because you log in.
