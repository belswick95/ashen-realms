# Movement and combat correction

The browser previously eased toward the latest 250ms position packet. This produces periodic acceleration/deceleration, drives the gait from that uneven movement, and transfers it directly to the following camera. Actors now use timestamped snapshot interpolation with a short presentation buffer. The camera follows the rendered position with a separate height/movement smoother. This is presentation only; collision, destinations, speed, combat and rewards remain authoritative in Postgres.

Speeds are now 3.2 world units/second walking and 6.4 running (previously 1.9/3.8). Running remains double walking, as requested. MMO units are not interchangeable: [RuneScape movement](https://runescape.wiki/w/Game_tick) is tile/tick based, while [Guild Wars 2](https://wiki.guildwars2.com/wiki/Movement_Speed) expresses speed in its own game units. These Eldervale values are a gameplay tuning choice, rather than a universal MMO speed standard. The buffering approach follows [Gaffer on Games' snapshot interpolation](https://gafferongames.com/post/snapshot_interpolation/).

Player foot clearance samples the terrain under the displayed soles rather than only the character centre, including floor/terrain height transitions. The adjustment affects the model, not server positions. Walk/run remain distance-driven with separate foot recovery paths. Teleports reset presentation history. Long frame times no longer multiply movement through a capped physics delta in the browser.

Equipment shows Stab, Slash and Lunge only when a weapon is wielded. Titles and accessible labels explain XP: Stab gives Attack XP; Slash Strength XP; Lunge divides the same total evenly between them. Distinct thrust, sweep and extended thrust poses are supported, including the scimitar. The server stores the selection. During an active wind-up, finish the strike before changing styles.

Attack level increases hit chance against the defender, with a 20%–98% bound; weapon accuracy also contributes. Strength increases the damage-roll ceiling. Defence level plus armor reduces the opponent's hit chance, bounded to avoid guaranteed immunity. Incoming attacks grant Defence XP (including blocked attacks). Style XP is awarded per attack rather than forcing all three combat stats to increase together on a kill. Lunge awards an integer half to each offensive skill; all three styles award the same total offensive XP for a given hit.

Validation includes a live authenticated walk with the owner's scimitar-equipped character, irregular packet timing tests, teleport history reset, real database style/XP and Defence-training transactions, existing gait/armor-clearance checks and a focused browser equipment/pose check. The live diagnostic account session was temporary and its token file is removed after use. This is not a capacity or poor-network load test.
